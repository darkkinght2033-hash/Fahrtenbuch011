Fahrtenbuch GitHub Pages – Version 21

Schäden jetzt direkt im vorhandenen App-Code repariert:

- Jeder Schadenseintrag hat „Bearbeiten“ und „Löschen“.
- „Bearbeiten“ lädt den Eintrag zurück in das normale Schaden-Formular.
- Änderbar: Datum, Kilometerstand, Bereich, Beschreibung, Status und Foto.
- Vorhandenes Foto bleibt beim Bearbeiten erhalten.
- Foto kann ersetzt oder entfernt werden.
- „Änderungen speichern“ aktualisiert denselben Auftrag.
- „Bearbeiten abbrechen“ setzt das Formular zurück.
- „Löschen“ entfernt den Auftrag nach Sicherheitsabfrage.

Die Fahrzeugfunktionen aus v19 bleiben erhalten.
